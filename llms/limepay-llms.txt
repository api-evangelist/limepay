# Limepay

> Limepay was a Melbourne-based Australian embedded-payments and white-label buy-now-pay-later (BNPL) company. Its developer surface let merchants and platforms accept card payments and offer pay-in-instalments through a drop-in Checkout and a REST API. Limepay was acquired by ASX-listed Spenda in 2024 and its product continued under the April Solutions brand; limepay.com.au now redirects to meetapril.com and the developer portal is gated behind a Redocly login.

This llms.txt was GENERATED by API Evangelist from the catalog profile (apis.yml) and repo artifacts on 2026-07-24. No machine-readable OpenAPI is downloadable for Limepay; the documented operation names below come from the historically public developer documentation.

## APIs

- [Limepay Payments API](https://docs.limepay.com.au/developer-portal/payments/): Accept and manage card and BNPL payments — create/pay orders, capture or void authorised transactions, issue refunds, save cards, run 3-D Secure and wallet (Apple Pay / Google Pay) payments. Operations: CreateOrder, PayOrder, GetOrder, CancelOrder, CreateOrderInvoice, CaptureTransaction, CancelUncapturedTransaction, GetTransaction, GetTransactionByOrderId, CreateRefund, CreateSavedPayCard, GetPayPlanEligibilityMaxAmount.
- [Limepay Platform API](https://docs.limepay.com.au/developer-portal/platform/): Onboard and manage sub-merchants for marketplaces — create platform merchants, merchant bank accounts and persons, run KYC, retrieve merchant tokens and settlement reports, issue platform refunds, look up supported industries. Operations: CreatePlatformMerchant, CreatePlatformMerchantBankAccount, CreatePlatformMerchantPerson, GetPlatformMerchant, ListPlatformMerchantPerson, GetPlatformSettlementReport, GetPlatformSupportedIndustry, CreatePlatformRefund.
- [Limepay Checkout](https://docs.limepay.com.au/developer-portal/checkout-integration/): Embeddable, customisable drop-in checkout for card + BNPL, with official plugins for WooCommerce, Magento 2, PrestaShop and Salesforce Commerce Cloud (parameter hidePayLaterOption toggles the pay-later option).

## Authentication

- Three scoped API keys, each sent as an HTTP Bearer token: Publishable (frontend/Checkout), Secret (server-to-server Payments API), Platform (Platform API administration). No OAuth2/OIDC.

## Official libraries

- [Limepay WooCommerce Gateway](https://wordpress.org/plugins/limepay-woocommerce-gateway/): Official WordPress/WooCommerce payment gateway plugin (v4.2.3).
- [limepay/module-lpcheckout](https://packagist.org/packages/limepay/module-lpcheckout): Official Magento 2 checkout module (v3.1.0).
- [limepay/lpcheckout](https://packagist.org/packages/limepay/lpcheckout): Official PrestaShop/PHP checkout module (v3.1.0).

## Notes

- Historical/defunct: acquired by Spenda (2024), continued as April Solutions (meetapril.com). Developer portal at docs.limepay.com.au is gated behind a Redocly login; the api.limepay.com.au host is retired (HTTP 404). Do not expect live endpoints.
